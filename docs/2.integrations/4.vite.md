# Vite migration

::warning
`@unlighthouse/vite` was removed in Unlighthouse v1. The historical npm package
remains deprecated and does not support v1. Use the [CLI](/integrations/cli) or
[CI runner](/integrations/ci) instead.
::

## Development

Start your Vite application as usual:

```bash
pnpm vite
```

Then run Unlighthouse against it from another terminal:

```bash
npx unlighthouse --site http://localhost:5173
```

The dashboard can rescan individual routes as you work without coupling the
scan lifecycle to Vite's HMR hooks.

## Build and CI

Start `vite preview` in an earlier process or CI service step:

```bash
pnpm vite preview --host 127.0.0.1
```

Run the CI scanner against that server from the scan step:

```bash
npx unlighthouse-ci --site http://localhost:4173
```

## Configuration

Keep Unlighthouse options in `unlighthouse.config.ts` rather than `vite.config.ts`:

```ts [unlighthouse.config.ts]
import { defineUnlighthouseConfig } from 'unlighthouse/config'

export default defineUnlighthouseConfig({
  scanner: {
    device: 'desktop',
  },
})
```

See [route definitions](/guide/guides/route-definitions) if your Vite project
uses a non-standard pages directory.
